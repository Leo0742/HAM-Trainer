# Source provenance

## Локальные документы

Проект использует две предоставленные пользователем копии:

- `Справочник_КЭ.pdf` — 233 страницы, издание 2015 года, А. Н. Заморока; точные формулировки, варианты и схемы;
- `radiolyubitel_2_category_guide_2026.pdf` — 104 страницы, редакция 1 августа 2026 года; выборка второй категории, темы, ответы и пояснения.

Контрольные суммы и уведомление о правах находятся в `ExamSources/README.md`. Локальный справочник 2015 года не выдаётся за текущую редакцию: официальная страница СРР сейчас ссылается на отдельный PDF 2020 года объёмом 229 страниц.

## Приоритет источников

- руководство 2026: состав второй категории, тема, тип, текст правильного ответа и исходное пояснение;
- справочник 2015: точная формулировка вопроса, варианты, исходный номер и схемы;
- `ContentAuthored/second-category-405-explanations.json`: единственный авторский учебный слой для всех 405 вопросов;
- `ContentOverrides/question-overrides.json`: явно проверенные расхождения и редакционные уточнения, применяемые последними.

Вопрос 201 сохраняет известное различие: руководство пишет «U или E», а вариант локального справочника содержит `U`. Приложение выбирает реальный option ID и отдельно хранит историко‑правовую заметку.

## Воспроизводимый конвейер

`import_questions.py` записывает нормализованный результат в `ContentRaw/`; `build_content.py` проверяет контрольную сумму неизменяемого авторского JSON, связывает его тексты со стабильными option/glossary ID и собирает итоговый банк. Точечные overrides содержат только проверенные source/answer-исправления. `source-map.json` связывает каждую из 405 карточек с обоими документами и страницами.

Полные PDF сохранены отдельно в `ExamSources/`. `extract_figures.py` создаёт 27 уникальных PNG и связывает их с 33 вопросами. Схема FM-передатчика совместно используется вопросами №173–176, а схема супергетеродинного приёмника — вопросами №177–180. `figure-manifest.json` хранит документ, страницу PDF, координаты crop, назначение и отметки визуальной проверки для каждого вопроса. Все фрагменты проверены на читаемость, соответствие вопросу и отсутствие красного печатного ключа ответа. Девять дополнительных учебных схем имеют собственные SVG-исходники и локальные PNG-рендеры для карточек глоссария.

`audit_answer_matches.py` хранит построчный отчёт: 400 exact и 5 explicit manual сопоставлений, без fuzzy guesses. `audit_option_sets.py` заново извлекает оба источника и проверяет все 405 формулировок, 1620 вариантов, порядок вариантов, стабильные option ID, правильный ответ, карту неправильных ответов, дубли и следы PDF-разметки. Пять явно документированных очисток удаляют только текст соседних таблиц, разделов и приложений, ошибочно попавший в конец варианта. `audit_content.py` считает только checksum-verified authored coverage, требует нулевой fallback и проверяет SHA-256 исходных PDF; автоматического «балла качества» нет.
