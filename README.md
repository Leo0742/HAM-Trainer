# HAM Trainer

Нативный офлайн‑тренажёр для подготовки к квалификационному экзамену радиолюбителя второй категории в России.

![Swift 6](https://img.shields.io/badge/Swift-6-F05138?logo=swift&logoColor=white)
![405 вопросов](https://img.shields.io/badge/банк-405_вопросов-2f7d6d)
![Offline](https://img.shields.io/badge/режим-offline-335c81)

Приложение написано на SwiftUI и работает полностью локально: без аккаунта, сети, телеметрии и API‑ключей. Внутри — точная выборка из 405 вопросов второй категории, адаптивное повторение, пробный экзамен и подробные объяснения на русском языке.

## Возможности

- умная очередь повторения: ошибки возвращаются позже, но не сразу;
- интервальное закрепление и отдельные состояния «слабый», «на повторении», «освоен»;
- пробный экзамен: 30 уникальных вопросов, проходной результат — 25/30;
- три уровня объяснений и разбор неправильных вариантов;
- глоссарий радиолюбительских терминов и вопросы со схемами;
- закладки, статистика по темам и локальное сохранение прогресса;
- экспорт и импорт резервной копии в JSON;
- светлая и тёмная темы macOS.

## Требования

- macOS 14 Sonoma или новее;
- Xcode Command Line Tools либо Xcode со Swift 6;
- Python 3 и Poppler (`pdftotext`, `pdftoppm`) — только для повторного импорта банка.

## Быстрый старт

```bash
git clone https://github.com/Leo0742/HAM-Trainer.git
cd HAM-Trainer

python3 Tools/import_questions.py \
  --reference /path/to/Справочник_КЭ.pdf \
  --guide /path/to/radiolyubitel_2_category_guide_2026.pdf

Tools/build_app.sh
open "Build/HAM Trainer.app"
```

Скрипт создаёт release‑сборку, стандартный пакет `.app`, иконку и локальную ad‑hoc подпись. Альтернативный путь — открыть `HAMTrainer.xcodeproj` и запустить схему `HAMTrainer` в Xcode.

> Исходные PDF и извлечённые из них страницы со схемами намеренно не публикуются. Импортёр создаёт 14 локальных изображений для 24 вопросов после того, как вы укажете собственные копии документов. Подробнее: [`Content/diagrams/README.md`](Content/diagrams/README.md).

## Как устроено обучение

После каждого ответа `AdaptiveReviewScheduler` обновляет состояние вопроса и следующую дату повторения. Неправильный ответ, «Не знаю» и просмотр ответа до попытки учитываются отдельно. Освоенные вопросы появляются редко, а слабые возвращаются в приоритетную очередь до устойчивого восстановления.

Прогресс автоматически сохраняется после каждого ответа:

```text
~/Library/Application Support/HAMTrainer/progress-v1.json
```

Для переноса данных используйте **Настройки → Экспорт JSON…** и **Импорт JSON…**. Формат резервной копии версионирован, а сброс прогресса требует подтверждения.

## Банк вопросов

Вторая категория представлена диапазонами `1–38`, `47–98`, `100–374` и `387–426` — всего 405 вопросов. Импортёр:

1. извлекает структуру из двух исходных документов;
2. берёт точные формулировки и варианты из справочника;
3. добавляет темы, ответы и объяснения из актуального руководства;
4. сопоставляет ответ со стабильным ID варианта;
5. останавливается при низкой уверенности сопоставления;
6. применяет ручные исправления из `ContentOverrides/question-overrides.json`;
7. формирует `questions.json`, `topics.json`, `source-map.json` и локальные схемы.

Каждый вопрос сохраняет ссылку на документ и страницу, поэтому исправления можно проверить и воспроизвести. Детали находятся в [`docs/source-provenance.md`](docs/source-provenance.md) и [`docs/content-format.md`](docs/content-format.md).

## Проверка

```bash
Tools/run_tests.sh
```

Набор проверок покрывает адаптивное повторение, ограничение повторов в сессии, интервалы освоения, восстановление слабых вопросов, пробный экзамен, сохранение/перенос прогресса и целостность всех 405 записей банка.

Последняя локальная проверка: **10/10 тестов пройдено**, целостность контента подтверждена, release‑приложение прошло `codesign --verify --deep --strict`.

## Конфиденциальность

HAM Trainer не выполняет сетевых запросов и не отправляет данные наружу. Весь прогресс хранится только в профиле текущего пользователя macOS. Перед публикацией форка проверьте права на используемые учебные материалы и изображения.

## Лицензия

Лицензия на исходный код пока не объявлена. Учебные документы и извлечённые из них материалы принадлежат их правообладателям и не входят в публичный репозиторий.
