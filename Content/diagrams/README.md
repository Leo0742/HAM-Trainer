# Схемы

`questions/` содержит 24 обрезанных изображения для 24 графических вопросов. Каждый PNG показывает только сравниваемые графики или схемы и исключает красный правильный ответ исходного справочника.

Полный исходный документ хранится отдельно в `ExamSources/Справочник_КЭ.pdf`. Восстановление фрагментов:

```bash
python3 Tools/extract_figures.py --reference ExamSources/Справочник_КЭ.pdf
```

Координаты crop зафиксированы в скрипте, включая вопросы, рисунок которых расположен на странице после начала текста.

`teaching/` содержит девять оригинальных векторных SVG-схем и их локальные PNG-рендеры для совместимости с `NSImage`. Карточки глоссария объясняют выводы и схемы включения транзистора, реактивные элементы и LC-контур, фазовую инверсию, супергетеродин, распределение тока и напряжения в диполе, вертикальную поляризацию и радиалы, КСВ и базовые фильтры. Это не экзаменационные рисунки; они показываются только после открытия термина и не раскрывают ответ до отправки варианта.
