# Локальные схемы

Эта папка предназначена для страниц со схемами, которые импортёр создаёт из локальной копии `Справочник_КЭ.pdf`.

PNG-файлы исключены из Git, потому что они являются извлечёнными фрагментами исходного учебного документа. Для их восстановления выполните из корня проекта:

```bash
python3 Tools/import_questions.py \
  --reference /path/to/Справочник_КЭ.pdf \
  --guide /path/to/radiolyubitel_2_category_guide_2026.pdf
```

После импорта здесь появятся 14 изображений, используемых в 24 вопросах банка.
